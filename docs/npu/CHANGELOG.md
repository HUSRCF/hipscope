# Changelog

## Unreleased

- tools/npu/a4-ec (dark, research): an out-of-tree hipfire probe (`tools/npu/a4-ec/probe`, path deps on wt-land-041m, no hipfire edits) that captures real dense-27B A4 prefill activations on gfx1201. It writes the pre-quant `x'` and the device `block_i4_128` bytes per IU4 GEMM input, for 8 layers × 4 tags, T = 4096, from the WT2 prompt `prompt-wt2.txt`. It is paired with a Rust CPU model of A4 error concentration, recovery (selective A8, outlier channels, low-rank) and NPU cost. Measured static top-20% block recovery is 0.293 (NSR-weighted), against a 0.5 kill threshold, so **the C1 selective-A8 NPU route is killed**. See `docs/a4-ec.md`.
- railgun::npu `fclk`: fabric-clock guard for concurrent GPU+NPU work on the Halo iGPU (amdgpu sysfs `power_dpm_force_performance_level` / `pp_dpm_fclk`). `FabricClockGuard` (RAII) is taken by `npu-coop` (every mode) and `npu-tools m4`; `NPU_FCLK_GUARD=require` (default) refuses unless perf is `manual` with only the top fclk level current, `pin` pins (direct write or `sudo -n tee`) and restores the prior perf level on drop or panic, `off` skips the check with a loud warning. The pin / verify / restore logic of `tools/npu/npu-window.sh` moved here; the script calls `npu-tools fclk pin|status|restore` (copy `npu-tools` with the other binaries). `tools/npu/npu-fclk-smoke.sh`.
- pm-npu `kernels::iu4_ief15_probe` + `crates/pm-npu/tests/ief15_probe.rs` + `npu-gemm --ief15-probe [--dump PATH] [--expected-only]` (IEF15 N0 window step 1, dark until the window): single-core semantics probe of every IEF15 core instruction (elementwise 16x16 acc64 VMUL/VMAC/VADDMAC all sign x shift16 x zero_acc, Horner chain, VNEG, raw bm round trip, VSRS_4x/2x over crSRSMode x shift x crRnd x crSat, VUPS_4x/2x, VLDB.UNPACK/VUNPACK, VSHUFFLE modes 12..19 and 2..9, VLT/VGE/VEQZ/VSEL/VADD/VSUB/VBAND/VBOR/VMAX_LT/VMIN_GE/VBCST, int8 8x8x8 control, scalar ALU) as a straight-line, dependency-spaced core program (437 cases in the const table `CASES`, 12.5 KB program). Expected bytes are the output of the exact PDI+TXN in the simulator; `--ief15-probe` submits it once on a fresh context and prints a per-case MATCH/MISMATCH table (nonzero exit on any mismatch). The simulator test checks every case against an independent lane model and the blob's determinism.

- npu-gemm: select Fast/Serial/LockOnly array cores, validate every packed LockOnly prefix without claiming GEMM throughput, and capture/decode AIE2P 504-byte packed-column status before context destruction on success or failure (`--dump-status`, including single-core GEMM). `tools/npu/npu-bisect2.sh` runs six bounded controls. V1 pass-through now uses legal same-index memtile cardinal lanes; staged routes are unchanged.
- pm-npu/pm-npu-sim/npu-gemm: shim DMA bandwidth probe (`kernels::bw_probe`, `npu-bw` binary, `npu-bw --sweep`): per column up to 2 read lanes (shim MM2S -> memtile S2MM cyclic sink) and 2 write lanes (memtile MM2S pattern source -> shim S2MM) with no cores, resubmittable dynamic TXN, token + SYNC per active channel; separates per-channel from aggregate (NoC/DDR) limits and read from write ceilings. The write source is finite (exactly `bytes`, a 16-BD chain) instead of cyclic so no words stay stranded in the switch for the next submit. Exact simulator gates for (1,1,0), (1,0,1), (8,2,2) and tail/repeat shapes, two submits per context.
- pm-npu-sim: core neighbour data memory (South 0x40000 / West 0x50000 / North 0x60000 windows) and neighbour lock views (ids 0..15 South, 16..31 West, 32..47 North, 48..63 own) via `Tile::step_with`/`Neighbours`, lent per step by `Config`; `vst.srs.4x ... srsSign1` int8 SRS stores (shift in `s0..s3`, crRnd floor/ceil/sym/half-modes, crSat wrap/saturate/symmetric) with `movx` to crSat/crRnd/crSRSMode and `movxm`/`mov` to `s` registers; unsourced modes return `Error::Unsupported`.
- pm-npu: V8 pair core `gemm_core::program_pair(kc, tiles, PairRole, Epilogue, Control)` (+ `tile_bds_pair`, `initial_locks_pair`): vertically adjacent cores share one 128-row A block through neighbour data memory (E/O halves, role-dependent South/North views, 9-step `PEER_FULL`/`PEER_EMPTY` lock protocol per chunk), with an optional int8 `VST.SRS.4x` C epilogue into a separate 8 KiB Cout buffer (`crSat=1`, `crRnd=0`, shift in `s0`); Fast and FastSlowCtl control disciplines. Later chunk 1137/1125 (Fast) or 1215/1199 (Slow) issue cycles, Int8 epilogue 532/546 per wave, programs <= 16 KiB. CPU-exact in a two-core simulator test (`crates/pm-npu/tests/gemm_core_pair.rs`).
- pm-npu: V9 `gemm_array::Variant::V9` / `design_v9` (int8 epilogue only): B resident in the memtile per N-wave and replayed to all `MW` M-waves (nw-outer wave order `w = nw*MW + mw`), with the V8 pair core programs unchanged. Two B slots (`0x14000 + slot*kc*4096`) are filled by a 2-BD producer and replayed by an `MW`-BD cyclic chain (odd-bank ids `[25,27,30,31,36..47]`, iteration `step = kc*1024` words, wrap 2 toggling the slot per traversal) under one shared ordered `B_EMPTY`(init 2)/`B_FULL` semaphore; C uses compact 64 KiB buffers (`0x4000`) with single-BD producers and shared lock pairs on core rows 1/3. Limits `MW <= 16`, `NW <= 8`, `kc <= 54` (`K <= 3456`). DDR read per submit is `8*4096*kc*(MW*NW + NW)` B (V8: `8*4096*kc*2*MW*NW`). The memtile BD iteration `current` is not cleared by a channel reset, so every dynamic TXN rewrites all resident memtile descriptors after the reset. Exact on silicon: gate_up 22.7 / down 21.6 TOPS busy with the V6 core map, 25.2 / 22.5 with the current default map (report.md).
- pm-npu/npu-gemm: V10 `gemm_array::Variant::V10` / `design_v10` (int8 epilogue only, `npu-gemm --variant V10`): mw-outer wave order `w = mw*NW + nw` with both operands resident in the memtile and each read from DDR once per submit (model host read `8*4096*kc*(MW + NW)` B; V9: `8*4096*kc*(MW*NW + NW)`, e.g. 4096 2560 640 reads 4.0625 MiB). The whole B segment (`NW*kc*4096` words) is filled once by one finite BD and replayed `MW` times by a cyclic MM2S BD under a single `B_FULL` semaphore; A is filled as full `kc*4096` slots and replayed to the NW tiles of each M-wave through a chain of NW BDs, one slot advance per traversal. V9 pair cores, routes and compact C descriptors are reused unchanged; V9 nw-outer layout and topology are untouched (V10 is a distinct resident topology). Limits `kc*(2+NW) <= 112`, `MW <= 16`, `NW <= 8`; Int8 epilogue only (`--epi i32` exits 2); same `--core Fast|FastSlowCtl`/`--ctl-probe`/`--a-from-hip`/`--reuse-ctx`/`--loop` flags as V9. Simulator/offline only, no silicon measurement; the printed ESTIMATE is a model.
