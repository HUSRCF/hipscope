# gfx1100 CK D256 BN128 Negative Result

## Scope

The full FlashAttention CK gfx11 generation matrix includes a D256 `BM64 x BN128` forward configuration. The hipfire staged Asym3-K/Q8-V sidecar previously accepted only `BN32/64` and its retained production build used `BM64 x BN32`. This experiment made the tile dimensions build-time parameters and compared the retained `64 x 32` configuration with `64 x 128`; it did not change runtime dispatch or default behavior.

## Attention-only filter

Both sidecars were rebuilt from the same source with scalar predecode stores and passed the quantized ABI smoke test. On a W7900/gfx1100, each point used five warmups and seven GPU-event trials with `Q=2048`, 24 query heads, 4 KV heads, and D256.

| K rows | BN32 staged CK | BN128 staged CK | BN128 / BN32 latency |
| ---: | ---: | ---: | ---: |
| 2,048 | 1.4019 ms | 1.3712 ms | 0.9781x |
| 4,096 | 3.4294 ms | 3.2971 ms | 0.9614x |
| 6,144 | 5.3648 ms | 5.4876 ms | 1.0229x |
| 8,192 | 7.8114 ms | 7.8069 ms | 0.9994x |

The candidate only helped the two shorter K sizes and was neutral or slower at the longer sizes that dominate PP16384.

## PP16384 production gate

The model-level gate used Qwen3.6-27B MQ4, Asym3 KV, group128/F32 semantics, 2048-token prefill chunks, three prefill repetitions per fresh process, three alternating process pairs, and 20-second idle intervals.

| Mode | Process median prefill | Raw process medians |
| --- | ---: | --- |
| CK BM64 x BN32 | 1124.90 tok/s | 1148.9, 1124.9, 1122.4 |
| CK BM64 x BN128 | 1124.80 tok/s | 1123.3, 1129.8, 1124.8 |

The paired ratios were `0.977718x`, `1.004356x`, and `1.002138x`; their median is `1.002138x` (`+0.21%`), with `2/3` positive pairs. All six processes emitted identical token IDs, including each baseline/candidate pair. This is effectively neutral and does not demonstrate a production-level win.

## Decision

Keep `BM64 x BN32` as the staged CK production configuration. Retain `CK_BM/CK_BN` only as build-time experiment controls and do not add a runtime flag or default route for `BN128`: these sweeps demonstrate no production-level win, not a universal BN128 regression. The mature CK `BN128` configuration is valid for this D256 pipeline, but its larger K tile did not improve the complete long-prefill workload measured here.
